# carbon-footprint-calculator
An application to calculate and track one's carbon footprint for various activities. 

### Running the project
#### Starting the backend
With Maven: Navigate to `backend` and run `mvn spring-boot:run` in the console. If Maven is not installed locally you can run `./mvnw spring-boot:run`
Or directly: Run the `CarbonFootprintCalculatorApplication.java` file under `src/main/java/poc/carbon_footprint_calculator`.  
#### Starting the frontend
Navigate to `carbon-footprint-calculator-frontend` and run `npm run dev`.
